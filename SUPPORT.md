# Support

WAF-Rejected is currently in **beta**. Support is best-effort and follows
[`docs/operations/support-policy.md`](docs/operations/support-policy.md).

## Getting help

1. Read the [user guide](docs/user-guide/README.md) and
   [configuration reference](docs/user-guide/configuration.md).
2. Check the [support matrix](docs/operations/support-matrix.md) for what is
   expected to work in this release.
3. Search existing GitHub issues.
4. Open an issue using the bug or feature template. Include version, build
   method (Nix/Cargo/container digest), configuration relevant to the problem
   (redact secrets), and a minimal reproduction.

## Security issues

**Do not open a public issue.** Follow [`SECURITY.md`](SECURITY.md) and use
GitHub private vulnerability reporting.

## Commercial and deployment support

This repository is the open-source project. There is no paid support
entitlement attached to it. Deployment-specific tuning, compliance evidence and
commercial arrangements are separate from the open-source project.

## Supported versions

Only the latest beta receives full support. See
[`docs/operations/support-policy.md`](docs/operations/support-policy.md) for the
support window and end-of-life rules.
