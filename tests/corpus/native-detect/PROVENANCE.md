# Native-detect parity oracle

`oracle.json` pins the decision of Coraza v3.3.3's `@detectSQLi` and
`@detectXSS` operators for every value in the CRS corpus plus a generated
variant/mutant corpus. It is the gate for
`waf::native_detect::tests::parity_with_coraza_on_pinned_oracle`.

## Format

A JSON array of objects:

| field | meaning |
|---|---|
| `s` | input value (UTF-8; may contain NUL, encoded as `\u0000`) |
| `q` | `libinjection.IsSQLi(s)` — what Coraza's `@detectSQLi` returns |
| `x` | `libinjection.IsXSS(s)` — what Coraza's `@detectXSS` returns |
| `k` | provenance: `crs`, `variant` or `mutant` |

Values are de-duplicated, non-empty and at most 8 KiB.

## Provenance

Generated by `native/coraza-sidecar/cmd/libinjection-oracle`, which links the
same vendored dependency Coraza v3.3.3 uses
(`github.com/corazawaf/libinjection-go v0.2.2`, BSD-3-Clause). Coraza's
`internal/operators/detect_sqli.go` and `detect_xss.go` are thin wrappers around
`libinjection.IsSQLi` / `libinjection.IsXSS`, so these verdicts are the
operators' verdicts.

* CRS source: `tests/corpus/crs/corpus.json` (2,112 cases), request method, URI,
  header names/values and body.
* Variants: case, whitespace, `/**/` comments, URL/HTML-entity encoding,
  full-width Unicode, zero-width space, doubled/backslash quotes, NUL
  substitution, JSON/form wrapping and truncation of SQLi, XSS and benign
  seeds.
* Mutants: deterministic byte edits (seeded RNG) over an operator-rich alphabet.

Regenerate with the command in `docs/suggestions_from_agents/native-detect.md`.
Do not hand-edit: the Rust test asserts zero differences in both directions.
